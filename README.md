# MATLAB 軟體操作與數理邏輯技術支援 Agent

## 專案簡介 / 初步構想
本專案旨在設計一個專為理工科學生或研究人員打造的教育型客服 Agent。透過整合 AI 大語言模型與學科知識庫，提供即時的 MATLAB 軟體操作指引與數理邏輯輔助，藉此分擔技術人員與教學助理的客服壓力。

## 核心功能與使用場景
本 Agent 主要鎖定 116 學年度進階數理課程中常見的痛點，提供以下技術支援：
*   **MATLAB 腳本除錯輔助**：當使用者在實作「最佳化方法 (Optimization Methods)」或處理龐大的「數學統計」數據時，協助初步判讀報錯訊息，並提供語法修正建議。
*   **數理邏輯與定理指引**：面對「實分析」或進階微積分等理論課程，提供數學定理證明的參考方向與邏輯架構梳理。
*   **自動化 FAQ 回應**：針對常態性的軟體安裝、環境變數設定等標準作業流程（SOP），提供快速且準確的步驟引導。

## 技術架構與開發計畫 (基於 Coze 平台)
*   **Phase 1**：建立基礎 Agent 架構與 GitHub 版本控制環境 (單元 0)。
*   **Phase 2**：導入並設定合適的 LLM，撰寫 System Prompt 以確立教育客服的角色語氣。
*   **Phase 3**：建置專屬知識庫 (Knowledge Base)，匯入 MATLAB 官方指南與數學推導講義。

## 課程作業評分與檢核聲明
*   本專案配合《人工智慧跨域應用》課程的實踐與檢核標準進行開發。
*   為符合課程 AI 評分系統的判讀機制，每週的開發進度與平台實作（如 Coze 介面設定、工作流配置等），皆會同步擷取網站上的實際操作畫面作為截圖佐證，並統一彙整於 PDF 學習文件中繳交。這能確保評分系統精準檢核實踐標準，避免因缺乏佐證而導致系統評分偏低的問題[cite: 3]。
