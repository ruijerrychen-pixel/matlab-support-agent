# MATLAB 軟體操作與數理邏輯技術支援 Agent

## 專案簡介 (Project Overview)
本專案旨在設計一個專為數學系與理工科系學生打造的「教育型客服 Agent」。在修習高等數學與應用科學課程時，學生常面臨將抽象數理邏輯轉換為程式碼的困難。本 Agent 透過整合大型語言模型（LLM）與專屬學科知識庫，提供即時的 MATLAB 語法除錯、報錯分析以及數學定理的邏輯指引，藉此大幅降低程式學習門檻，並有效分擔教學助理（TA）與技術人員的客服壓力。

## 核心應用場景 (Core Scenarios)
本 Agent 鎖定日常學術研究與課堂作業中最常遇到的痛點，提供以下三大核心支援：

*   **最佳化方法 (Optimization Methods) 腳本除錯**：
    協助判讀 MATLAB 執行最佳化演算法時的報錯訊息。例如在設定限制條件時，協助使用者精準定義變數的矩陣性質（如：除錯並確認矩陣 $d$ 為半正定矩陣，而非單純的數值比較關係），提供正確的語法修正建議與參數調整方向。
*   **數學統計 (Mathematical Statistics) 數據處理**：
    針對龐大的統計數據集，提供資料清理、機率分配擬合、假說檢定等 MATLAB 內建函數的使用指引，並協助釐清統計模型背後的數學假設與運算邏輯。
*   **進階數理邏輯與定理指引**：
    面對「實分析 (Real Analysis)」等高度理論課程，Agent 可協助梳理證明題的邏輯架構。例如協助釐清推導過程中的變數關係（確認特定表達式為 $x^2$ 還是 $n/x$ 等細節），提供定理證明的參考起手式與推導方向。

## 目標受眾 (Target Audience)
*   **中央大學數學系及理工學院學生**：正在修習 116 學年度相關數理與程式應用課程的大學生與研究生。
*   **學術研究人員**：需要快速利用 MATLAB 進行數值模擬與演算法驗證的實驗室人員。
*   **軟體代理商與技術客服**：可作為企業級客服系統的前端攔截器，自動處理高度重複的基礎語法問題。

## 系統架構與技術規劃 (Architecture & Roadmap)
本專案將基於 Coze 平台進行低程式碼（Low-code）開發，預計分為三個階段推進：

1.  **環境建置與流程設計 (Phase 1)**：
    完成 GitHub 專案庫建立與版本控制環境，並於 Coze 平台設計初步的 Chatflow 工作流。建立意圖識別（Intent Recognition）機制，區分使用者當下的問題屬於「語法錯誤」還是「數學理論盲點」。
2.  **知識庫導入與 RAG 應用 (Phase 2)**：
    建置專屬知識庫（Knowledge Base），匯入 MATLAB 官方技術文件、常見錯誤代碼（Error Codes）表，以及數理課程講義。讓 Agent 能透過檢索增強生成（RAG）技術，給出具有學理依據的精準解答。
3.  **記憶機制與個人化支援 (Phase 3)**：
    設定記憶機制（Memory）以記住使用者的數學程度、常犯錯誤與過往詢問習慣，提供更具連貫性與個人化的程式除錯教學。
